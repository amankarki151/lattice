# Benchmark results

Generated by `bench/run.py`. Numbers are from a single machine and will vary on yours.

Dataset: SIFT, 10000 base vectors, 128 dimensions, k=10.
Ground truth is SIFT's own precomputed neighbour list.

| system | build (s) | recall | p50 (us) | p99 (us) | mean (us) |
|---|---|---|---|---|---|
| Lattice (ef=10) | 18.5 | 0.8980 | 237 | 407 | 238 |
| Qdrant (in-memory) | 0.6 | 1.0000 | 2094 | 2621 | 2104 |
| Chroma | 0.4 | 0.9970 | 311 | 361 | 306 |

## Caveats

Qdrant and Chroma are full services with networking, persistence policies, filtering, and metadata support. Lattice is an embedded library. Some of their extra latency buys features Lattice does not have, so this is not a like-for-like comparison and should not be read as one.

Qdrant is run in `:memory:` mode to remove the network hop, which is the closest available approximation to an embedded library.
